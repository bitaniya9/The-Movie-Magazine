# The Movie Magazine

## Description

A full stack movie review platform where users can browse movies,read reviews made on the page, submit their own review , add a favorites or add to watch list.The movie data is fetched from TMDB and synchronized into a Postgresql database.

## Features

- User registration and login
- JWT Authentication
- Browse trending, popular, kids shows and top-rated movies
- Search movies
- Movie detail pages
- Submit ratings and reviews
- Edit and delete reviews
- RESTful API
- Postgresql database

## Tech Stack

### Backend

- Node.js
- Express.js
- bcrypt
- Postgresql
- JWT

### Frontend

- React
- CSS
- Axios

### External API

- TMDB API
